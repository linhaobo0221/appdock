# AppDock.link

**Small apps, thoughtfully made.**

[English](./README.md) · [简体中文](./README.zh-CN.md) · 日本語

AppDock.link は、小さく目的の明確なアプリを集めたプロダクトホームです。本リポジトリには [appdock.link](https://appdock.link/) で公開する静的 Web サイトが含まれています。

## AppDock.link について

AppDock.link は、機能を必要最小限に保ち、プライバシーと長期的な使いやすさを大切にする小さなアプリのコレクションです。各アプリは独立した製品ページと安定した URL を持ち、共通のブランドと設計原則を使用します。

現在のプロダクト：

- [朝晩体重](https://appdock.link/dailyWeight/)：朝と夜の体重を分けて記録し、日内変化と長期トレンドを確認できます。暗号化 PNG によるバックアップと復元は端末内で完結します。

## リポジトリ構成

- `/index.html`：AppDock.link のプロダクト入口
- `/dailyWeight/`：朝晩体重の紹介ページ
- `/assets/`：AppDock.link のブランドおよび共通アセット
- `/CNAME`：GitHub Pages のカスタムドメイン
- `/.nojekyll`：静的ファイルをそのまま配信するための設定

今後のプロダクトは `/otherApp/` のような独立ディレクトリに追加し、既存 URL を変更しません。

## ローカルプレビュー

リポジトリのルートで次を実行します。

```bash
python3 -m http.server 4173
```

次の URL を開きます。

- `http://127.0.0.1:4173/`
- `http://127.0.0.1:4173/dailyWeight/`

## 公開方法

本サイトは GitHub Pages でホストします。既定ブランチのリポジトリルートを Pages の公開元に設定し、`CNAME` の `appdock.link` を維持してください。DNS の検証後は HTTPS を有効にします。
