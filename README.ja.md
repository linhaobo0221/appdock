# AppDock.link

**Small apps, thoughtfully made.**

[English](./README.md) · [简体中文](./README.zh-CN.md) · 日本語

AppDock.linkは、小さく、目的が明確なアプリを紹介する公式サイトです。本リポジトリには、[appdock.link](https://appdock.link/)で公開する静的Webサイトが含まれています。

## AppDock.link について

AppDock.linkは、機能を必要最小限に絞り、プライバシーと長く使えることを大切にした小さなアプリを開発しています。各アプリには専用の製品ページと固定URLがあり、共通のブランドと設計思想を共有しています。

公開中のアプリ：

- [朝晩体重](https://appdock.link/dailyWeight/)：朝と夜の体重を分けて記録し、日内差や長期的な推移を確認できます。暗号化PNGによるバックアップと復元は、すべて端末内で行われます。

## リポジトリ構成

- `/index.html`：AppDock.linkの製品一覧ページ
- `/dailyWeight/`：朝晩体重の紹介ページ
- `/assets/`：AppDock.linkのブランド素材と共通アセット
- `/CNAME`：GitHub Pagesのカスタムドメイン
- `/.nojekyll`：静的ファイルをそのまま配信するための設定

今後追加するアプリは、`/otherApp/`のような独立したディレクトリに配置し、既存のURLは変更しません。

## ローカルプレビュー

リポジトリのルートで次を実行します。

```bash
python3 -m http.server 4173
```

次の URL を開きます。

- `http://127.0.0.1:4173/`
- `http://127.0.0.1:4173/dailyWeight/`

## 公開方法

本サイトはGitHub Pagesで公開します。既定ブランチのリポジトリルートをPagesの公開元に設定し、`CNAME`の`appdock.link`を維持してください。DNSの検証後はHTTPSを有効にします。
