# Figma assets

These SVG glyphs were downloaded unchanged from the Daily Weight Figma design, [landing-desktop-v2 (32:1050)](https://www.figma.com/design/YCvqTu5HwjEMYf5p2YEwTO/?node-id=32-1050).

The app icon in `../images/app-icon.svg` is the original vector export of node `23:321`. The favicon and Apple touch icon are rasterized from that SVG for browser compatibility.

All phone screens, charts, cards, keypads, gradients, and backup artwork are HTML/CSS. No page or app screenshots are used as website assets.
