# 朝晩体重

[English](./README.md) · [简体中文](./README.zh-CN.md) · 日本語

プロダクトページ：[appdock.link/dailyWeight](https://appdock.link/dailyWeight/)

## プロダクト概要

朝晩体重は、アカウント登録を必要とせず、端末内のデータを中心に設計された体重記録アプリです。朝と夜の体重を分けて記録し、1回の測定値を過度に評価するのではなく、日内変化、一晩の変化、長期的な傾向を確認できます。

主な特徴：

- 朝と夜の体重を分けて記録
- 日内差、一晩の変化、週・月単位のトレンドを表示
- 端末内で朝と夜のローカル通知を設定
- アカウント不要。体重記録と設定を AppDock へアップロードしない
- 端末内で暗号化 PNG を作成し、元の画像からデータを復元
- 広告、トラッキング、アクセス解析、クラッシュレポートを組み込まない

朝晩体重は医療機器ではなく、診断、治療、医療上の助言を提供しません。記録、計算結果、トレンドは一般的な参考情報です。
